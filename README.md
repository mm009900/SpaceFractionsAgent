SpaceFractionsAgent: Autonomous Code & Architecture Agent for Space Fractions Game
SpaceFractionsAgent is an intelligent software engineering agent framework designed for the Space Fractions interactive educational game. It parses architectural documentation and PlantUML system views to automatically build and output a local, standalone Electron desktop application.
✨ Features
Architecture Data Extraction: Automatically parses architectural specifications (Architecture_Documentation.md) and PlantUML diagrams (Architecture_View.md) into structured JSON inputs (architecture_input.json).

Automated Code Agent: Processes architectural requirements to dynamically synthesize full project files and frontend UI code.

Native Desktop Application: Generates an Electron-based standalone desktop environment without requiring a web browser.

End-to-End Workflow: Unified pipeline covering parsing, code generation, local project packaging, and application execution.

🚀 Quick Start
Prerequisites
Ensure you have the following installed on your system:

Python (v3.8 or higher)

Node.js (v18 or higher) & npm

Installation & Setup
1.Clone the repository:
git clone https://github.com/mm009900/SpaceFractionsAgent.git
cd SpaceFractionsAgent
2.(Optional) Parse Architecture Files:
If you modify the architectural documentation or PlantUML diagrams, update architecture_input.json by running:
python parser.py
🎮 Generating and Running the Application
1. Launch the Code Agent
Run agent.py to process architecture_input.json and generate the desktop application project inside the generated_project/ folder:
python agent.py
2. Launch the Desktop Application
Navigate into the generated application folder, install the required dependencies, and launch the Electron application:
cd generated_project
npm install
npm start

│   │   └── index.html            # Standalone desktop game UI
│   ├── main.js                   # Electron main process script
│   └── package.json              # Project configuration and desktop start scripts
└── README.md                     # Repository documentation
